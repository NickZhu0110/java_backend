# Qt Source Modules

This directory contains the desktop client's focused viewer, data, cache, HTTP artifact, and vessel UI modules.

## Directory map
- [`viewer`](viewer): CT/MPR rendering, mask editing, VTK 3D, and direct NIfTI review.
- [`data`](data): native CT and binary-mask value models.
- [`cache`](cache): local case/job artifact paths and metadata.
- [`io`](io): backend artifact download, upload, and recalculation requests.
- [`vessel`](vessel): experimental VMTK process control and CPR result window.
